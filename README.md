# 🌍 Travelling Landing Page

A simple and modern travelling landing page built using **HTML** and **CSS**.  
This project showcases a clean user interface with a full-screen background image, transparent navbar, centered hero text, and a call-to-action button.

---

## 🚀 Features

- Full-screen background hero section  
- Transparent navigation bar  
- Smooth hover effects  
- Centered main headline and sub-text  
- Clean, modern UI design  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- Google Fonts (Montserrat)
